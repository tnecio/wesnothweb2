# fixtures

Checked-in ground-truth output from the native oracles (see
`../README.md`). Each oracle gets its own subdirectory named after it,
minus the `wl-`/`-oracle` decoration, e.g. `fixtures/image-oracle/`.

These are regenerated by re-running the relevant oracle binary and
overwriting the subdirectory -- they are not hand-written and should not be
hand-edited. Regenerating requires the native build (see `../README.md`);
consuming them (ordinary `npm test`) does not.
